Everything a daily browser needs

Blocking, privacy and the tools you use every day, packed into one compact Android app.

Ad and tracker blocking

Filter lists such as EasyList and EasyPrivacy, pop-up and redirect controls, per-website settings, your own blocked-domain list, optional Strict Mode and blocked-request statistics.

Privacy controls

Private tabs, third-party cookie blocking, Safe Browsing, an optional app lock that uses your screen lock or biometrics, and clearing of browsing data whenever you choose.

Password vault

Saved passwords are encrypted with AES-256-GCM and the key is protected by Android Keystore. Open it with optional biometrics, generate passwords, and use Android Autofill. Passwords are left out of regular backups.

Everyday tools

Tabs, tab groups and pinned tabs, bookmarks and history, Reader Mode, page translation, desktop-site mode, a download manager with pause and resume where the site supports it, and saving pages as PDF.

A start page that helps

Weather from Open-Meteo in °C or °F, optional news from public RSS feeds, and shortcuts you can customise. Weather and news can be turned off.

Developer tools

WebView developer tools with Elements, Console, Network, Sources and Application panels. Some advanced Chrome DevTools features aren’t available in Android WebView.

Clear about what connects to the internet

No DEXTA account is needed, and saved passwords stay encrypted on your device. A few optional features do contact other services:

Weather
Open-Meteo receives approximate, rounded location coordinates when weather is used.
Translation
Text you select is sent to Google’s translation endpoint.
Safe Browsing
Uses Google’s Safe Browsing service when you turn it on.
Search suggestions
Address-bar text may go to your chosen search provider when suggestions are on.
News
DEXTA requests the public RSS feed you select.
Updates
DEXTA checks this repository’s public release information.

Private browsing doesn’t make you invisible to websites, your internet provider or network operators. The full details are in the README.

Install in four steps

DEXTA is installed from the APK file, not from Google Play.

  1. Download the APKUse the button on this page. It comes from the official GitHub Releases page.
  2. Open the downloaded fileFind it in your browser’s downloads or in your file manager.
  3. Allow the install if Android asksAndroid may ask you to allow installs from that browser or file manager.
  4. Review the prompt and installCheck the details Android shows, then confirm.

Download DEXTA only from this official repository. Android may show a warning for apps installed outside Google Play. After installing, DEXTA can check for updates itself and always asks for your approval before an update is installed.

Questions

Straight answers, including the limits.

Is DEXTA really free?

Yes. There is no premium tier, no paid subscription and no in-app advertising.

Do I need an account?

No. DEXTA doesn’t require registration or a DEXTA account.

Which Android versions does it support?

Android 8.0 (API 26) and newer. DEXTA uses Android System WebView as its browser engine.

Will it block every ad?

No blocker can promise that, and some ads may still appear. You can adjust protection for a single website, or turn blocking off for a site that doesn’t work, and only for sites you trust.

Does DEXTA support Chrome extensions?

Not Chrome Web Store extensions. DEXTA supports user scripts instead.

How do I update DEXTA?

DEXTA can check for updates itself. When a new version is available it asks you to confirm, and Android asks for your approval before installing. You can also download the latest APK from this page.

Ready to try DEXTA?

Free, no account, no in-app ads. Found a bug or have an idea? Tell us on GitHub.
